## APIs

### Env0

env0 is an infrastructure-as-code automation platform providing cost
estimation, policy enforcement, and self-service environments. The
public REST API is available at `https://api.env0.com/` and uses HTTP
Basic authentication with API key credentials. Rate limits are 1,000
requests per 60 seconds.
